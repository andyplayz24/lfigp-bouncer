# LFIGP Bouncer

Event sign-ups and door check-in for LFIGP.

- **Sign-up page:** `index.html?event=EVENT_ID` (share this link per event from the app)
- **Door app:** `app.html` (unlock with your admin key; add it to your home screen)

Guest lists, scans and payments live in the organizers' Google Sheet. No keys or personal data are stored in this repository.
